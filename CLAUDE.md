## Layout
- `core/Core.lua` namespace `OctoBG`, saved variables (`OctoBGDB`, defaults merged), pcall'd event
  bus `B:On(event, fn, bgOnly)`, ticker `B:Every(sec, fn, bgOnly)`, internal messages `OBG_*`
  (`OBG_INIT`, `OBG_ZONE`, `OBG_LAYOUT`, `OBG_ACTIVE`, `OBG_ENEMY`), zone keys WSG/AB/AV/TG/ARENA.
  bgOnly handlers/tickers run only while `B.active` (in a BG/arena, layout mode, or world HUD on);
  events only they want are unregistered from the client otherwise.
- `core/Util.lua` GUID + DLL wrappers, panels (`U.Panel`, positions in `db.pos[key]` as TOPLEFT),
  `U.SendBG` (1/s, same text once per 4 s), `U.Alert`, `U.Rotate` (8-arg SetTexCoord).
- `core/Map.lua` world/map conversion, facing, calibration, landmarks, WSG describer.
- `core/Tracker.lua` enemy players by GUID.
- `core/Widgets.lua` option widgets (Check / Slider / Dropdown / Color / Edit / Buttons / Note /
  Live) in folding cards on scrolling pages, two to a row, help in tooltips; every widget has
  Refresh (see "Options overhaul" below).
- `core/Layout.lua` move mode: the hover toolbar on each blue box, per-panel size / opacity
  (`db.panels[key]`), right-click / wheel on boxes, grey "(off)" boxes.
- `data/` EnemyCooldowns' spell, reset and DR tables, renamed `ECD_X` -> `OctoBG.CDData.X`
  (values unchanged; a PowerShell regex did the rename, see the file headers).
- `modules/` Cooldowns (engine: casts, learning, resets, DR, immunities, alerts, profile, import of
  the old addon), CDBars (target cooldown bars), CDPlates (nameplate icons), Flags, Timers (spirit +
  objectives + start + AB prediction + big res), Casts (enemy casts, data only), Focus, People (Spy's
  player database), Nearby (Spy's lists, alerts, zone rules), Roster (enemy list = Spy's Nearby
  window), Stats (Spy's statistics window), Incoming, HUD, TacMap (enemy map), Minimap (button +
  quick menu), Options (window with topic pages + slash commands).
- `media/*.tga` generated by `tools/MakeTextures.ps1` (white + alpha, coloured in game; byte-identical
  when re-run). `media/sounds`, `media/fonts`, `bar-*`, `button-*`, `resize-*` copied from Spy.
- `tests/run.ps1` runs every file through `tests/mock.lua` (permissive 1.12 mock: unknown widget
  methods are no-ops, methods 1.12 lacks raise) on DmorphOcto's LuaHost; 270 checks. Run it with
  `powershell -ExecutionPolicy Bypass -File tests\run.ps1` (scripts are disabled on this machine).
